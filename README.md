# Последняя линия — прототип 0.1

Текстовая интерактивная детективная драма на русском языке.

## Уже работает
- Адаптивный интерфейс для компьютера и телефона.
- Сцена диспетчерской с CSS-иллюстрацией 2D-персонажа и лёгкой анимацией.
- Первый игровой эпизод с ветвящимися решениями.
- Показатели доверия заявителя, точности оценки и репутации.
- Журнал улик и последствия решений.
- Перезапуск эпизода.

## Запуск
Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.

## Следующие этапы
1. Экран начала карьеры и профиль персонажа.
2. Продолжение эпизода: выезд, опрос свидетелей, осмотр места и версии.
3. Система сохранения и переменных расследования.
4. Оригинальные 2D-портреты с эмоциями и анимации смены сцен.
5. Развёртывание на GitHub Pages или Cloudflare Pages.

Все персонажи и происшествия вымышлены.
