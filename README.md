# Последняя линия — версия 1.4.0

Адаптивная русскоязычная интерактивная детективная история. Статический сайт: без Node.js, npm, React или сборки.

## Быстрый запуск
Откройте `index.html` в браузере.

## Публикация в Cloudflare Pages
Для прямой загрузки:
1. В Cloudflare откройте Workers & Pages → Create → Pages → Direct Upload.
2. Загрузите папку, содержащую `index.html`, `_headers` и `_redirects` (или ZIP с этими файлами в корне архива).
3. Если проект подключён к GitHub: Framework preset = None; Build command = `npm run build`; Build output directory = `dist`; Root directory — корень репозитория. Скрипт сборки копирует страницу и папку `assets/` в `dist/`.
4. После публикации откройте адрес проекта и проверьте, что главная страница загружается.

Если Cloudflare продолжит выдавать ошибку, сохраните точный текст ошибки или скриншот экрана deployment/build logs: ошибка может быть связана с настройкой существующего проекта, а не с файлами игры.

## Что включено
- Пиксельная стилизация интерфейса, увеличенный контраст и более крупный текст. На главном экране описание дела показывается в верхнем досье и не дублируется на кнопке выбора.
- Пиксельные SVG-спрайты оператора в форме с гарнитурой, заявительницы и сотрудника экипажа.
- Пиксельная рабочая станция: мониторы вызовов, карта городской сети, клавиатура, рация и кружка; отдельные капли дождя падают перед силуэтом многоэтажного города.
- Карьерный режим выживания: игрок начинает с короткого пиксельного инструктажа, затем получает случайное дело на каждый рабочий день. Вручную выбрать дело нельзя.
- Цель — пройти как можно больше рабочих дней подряд. После успешного завершения дела открывается следующий день и случайно назначается новое дело; критическая ошибка завершает карьеру.
- Пять сюжетных дел в случайной ротации: возможное проникновение в дом, поиск пропавшего ребёнка, тревожный вызов из аптеки, пропавший жилец в многоэтажке и автобус, исчезнувший после последнего рейса.
- Дополнительные сцены с опросом свидетелей, временными линиями, проверкой системных часов и сопоставлением независимых источников.
- В отдельных сценах доступны дополнительные варианты решения, если игрок ранее собрал соответствующую улику; некоторые ошибки ведут к отдельным критическим исходам.
- Скрытые случайные события: повторный звонок, устаревшая системная отметка, перераспределение ресурсов или неожиданно вспомнившийся факт свидетеля. Последствия не всегда видны в тексте выбора.
- Показатель репутации влияет на стартовые условия следующего дня; прогресс карьеры и число пережитых дней сохраняются в браузере.
- Обновлённый пиксельный интерфейс: кинематографический экран инструктажа, более чёткая сетка, контрастные рамки, пиксельная городская панорама, адаптация вступления под телефон.
- Фатальные ошибки в критических выборах: проигрыш с объяснением последствий и возможностью начать заново.
- Показатели доверия, точности и репутации.
- Журнал улик, список персонажей, карточка дела и хронология решений.
- Итоговый отчёт, возможность пройти заново.
- Автоматическое сохранение в localStorage.
- Улучшенная мобильная версия: крупные сенсорные кнопки, более удобная раскладка дела и игровых решений, адаптация под узкие экраны; учёт prefers-reduced-motion.
- Опциональные синтезированные звуковые эффекты телефонного вызова, стука, шагов, открытия и закрытия двери, радиосвязи и помещения; звуки связаны с игровыми сценами и действиями, звук выключен по умолчанию.
- Таймер на отдельных критических решениях; истечение времени автоматически ведёт к неблагоприятному доступному выбору.
- После решения отображаются последствия и изменения игровых показателей.

Все персонажи и происшествия вымышлены. Игра — художественное произведение, а не руководство по реагированию на реальные чрезвычайные ситуации.

## Ограничения текущей версии
Сохранение хранится локально в браузере и не синхронизируется между устройствами. Звуки генерируются средствами Web Audio API, а не записаны с реальных источников. Для воспроизведения включите звук в интерфейсе: браузер не разрешает автоматическое воспроизведение звука до взаимодействия пользователя. Визуальные сцены и последствия — художественная симуляция; дальнейшие улучшения могут добавить больше уникальных спрайтов, анимаций и разветвлений.
